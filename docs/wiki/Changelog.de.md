# Changelog

Der Changelog wird nicht hier gepflegt.

Es gibt genau einen Changelog, [`CHANGELOG.md`](https://github.com/Xerolux/violet-hass/blob/main/CHANGELOG.md)
im Wurzelverzeichnis des Repositories, und der Release-Workflow übernimmt den
Abschnitt einer Version daraus wörtlich auf die GitHub-Release-Seite. Eine
zweite, von Hand gepflegte Kopie auf dieser Seite blieb bei 2.3.x stehen und
erzählte Lesenden etwas anderes als die Release-Notes – deshalb wurde sie
entfernt statt aktualisiert.

## Wo steht was

| Gesucht | Ziel |
|---|---|
| Die vollständige Historie, alle Versionen | [CHANGELOG.md](https://github.com/Xerolux/violet-hass/blob/main/CHANGELOG.md) |
| Inhalt eines bestimmten Releases | [GitHub Releases](https://github.com/Xerolux/violet-hass/releases) |
| Der neueste stabile Download | [Aktuelles Release](https://github.com/Xerolux/violet-hass/releases/latest) |
| Etwas funktioniert nach einem Update nicht mehr | [Fehlerbehebung](Troubleshooting.de) |
