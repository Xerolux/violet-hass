# Changelog

The changelog is not maintained here.

There is exactly one changelog, [`CHANGELOG.md`](https://github.com/Xerolux/violet-hass/blob/main/CHANGELOG.md)
in the repository root, and the release workflow lifts a version's section from
it verbatim onto the GitHub release page. A second, hand-written copy on this
page went stale at 2.3.x and told readers a different story than the release
notes did, so it was removed rather than updated.

## Where to read what changed

| You want | Go to |
|---|---|
| The full history, every version | [CHANGELOG.md](https://github.com/Xerolux/violet-hass/blob/main/CHANGELOG.md) |
| What a specific release contains | [GitHub Releases](https://github.com/Xerolux/violet-hass/releases) |
| The newest stable download | [Latest release](https://github.com/Xerolux/violet-hass/releases/latest) |
| Something that broke after an update | [Troubleshooting](Troubleshooting) |
